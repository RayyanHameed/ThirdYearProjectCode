This repository contains the code for my third year project.
It contains 3 files.
The main file is the Clean_experiment_file.ipynb.
This jupyter notebook contains everything you need to run(and reproduce) the experiments that I found for my third year project.
The Project_code_clean_file contains all the code I programmed myself for the project- things like the code for the superviesd and self supervised methods as well as code for the spatially varying methods.
It also contains some of the code for the Golden Section Search method that I had tried during the testing phase.
The final file is the Tutorial_Codes file which was kindly shared by Dr Kostas Papafitsoros and contains the code for the Chambolle Pock Primal Dual algorithm that we used to solve the tv denoising problem.
